  - { amount: 2, unit: "tbsp", item: "mild curry paste" }
  - { amount: 2, unit: "cans", item: "chickpeas, drained and rinsed" }
  - { amount: 400, unit: "ml", item: "coconut milk" }
  - { amount: 200, unit: "g", item: "baby spinach" }

  - { item: "Steamed rice, to serve" }
instructions:
  - "Warm the oil in a deep pan. Add the onion and cook gently for 6–8 minutes until soft."
  - "Stir in the curry paste and cook for 1 minute, then add the chickpeas and coconut milk. Bring to a gentle simmer."
  - "Cook uncovered for 15 minutes, stirring now and then, until creamy. Fold in the spinach until just wilted."
  - "Finish with lime juice and coriander. Serve with rice."

This is a forgiving, cupboard-friendly supper. Add a splash of water if you’d like a looser sauce.
